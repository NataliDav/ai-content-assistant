# 🤖 ИИ-ассистент для написания контента в блог

Веб-приложение для генерации постов для блога с помощью искусственного интеллекта. Поддерживает работу с локальной нейросетью **Ollama** (бесплатно, без интернета) и внешними ИИ-провайдерами: **OpenAI**, **Anthropic Claude**, **DeepSeek**, **ProxyAPI**.

---

## ✨ Возможности

- 🧠 **Несколько ИИ-провайдеров** — Ollama (локально), OpenAI, Anthropic Claude, DeepSeek, ProxyAPI
- 💬 **Интерактивный чат** с нейросетью, учитывающий историю диалога
- 📄 **Загрузка роли из PDF** — полный текст документа становится системным промптом (пригодится для «вайб-копирайтеров», редакторов тона и т.д.)
- 👥 **Настройка целевой аудитории** — ЦА, тон контента, примеры текстов
- 📊 **Автоматическое сохранение постов** в CSV-файл (`сгенерированные_посты.csv`)
- ⬇️ **Экспорт постов** в CSV прямо из интерфейса
- 🔋 **Автозапуск Ollama** — сервер сам запустит локальную модель, если она установлена
- 🔑 **Проверка API-ключей** — валидация ключей внешних провайдеров лёгким запросом
- 🌙 **Без внешних зависимостей** — бэкенд на чистом Python (только `pypdf` для PDF)

## 🚀 Быстрый старт

### Требования

- **Python 3.8+**
- Один из вариантов нейросети:
  - **Ollama** (рекомендуется, бесплатно): [ollama.com](https://ollama.com) + модель `qwen2.5:3b`
  - **API-ключ** одного из провайдеров: OpenAI, Anthropic, DeepSeek, ProxyAPI

### Установка

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/ВАШЕ_ИМЯ/ai-blog-content-assistant.git
cd ai-blog-content-assistant

# 2. Установите зависимость (парсинг PDF)
pip install -r requirements.txt
```

### Запуск

```bash
# Способ 1: скрипт запуска (запускает сервер и открывает браузер)
./start.sh

# Способ 2: вручную
python3 server.py
```

Затем откройте в браузере: **http://127.0.0.1:8000**

### Настройка нейросети

**Вариант А — Ollama (бесплатно, локально):**
```bash
pip install ollama          # не нужно, сервер работает напрямую с API
ollama pull qwen2.5:3b      # скачать локальную модель
```
Сервер сам обнаружит и запустит Ollama.

**Вариант Б — внешний ИИ с API-ключом:**

Через интерфейс (рекомендуется) или переменные окружения:
```bash
export OPENAI_API_KEY=sk-...      # или ANTHROPIC_API_KEY, DEEPSEEK_API_KEY, PROXYAPI_API_KEY
```

## 🔌 API

Бэкенд предоставляет REST API с CORS-поддержкой:

| Метод | Эндпоинт | Описание |
|---|---|---|
| `GET` | `/` | Главная страница (интерфейс) |
| `GET` | `/api/settings` | Настройки (ЦА, примеры, тон) |
| `GET` | `/api/status` | Статус ИИ-провайдера и моделей |
| `POST` | `/api/chat` | Диалог с нейросетью, генерация поста |
| `POST` | `/api/extract-pdf` | Извлечение текста из PDF |
| `POST` | `/api/save-settings` | Сохранение настроек |
| `POST` | `/api/apply-role` | Применение роли как системного промпта |
| `POST` | `/api/ollama/ensure` | Запуск/проверка Ollama |
| `POST` | `/api/check-key` | Проверка API-ключа провайдера |

### Пример запроса к `/api/chat`

```bash
curl -X POST http://127.0.0.1:8000/api/chat \
  -H "Content-Type: application/json" \
  -d '{
    "роль": "SMM-специалист",
    "ца": "Молодые мамы",
    "тон": "Дружелюбный",
    "примеры": "Как я экономлю время на готовке",
    "сообщение": "Напиши пост о пользе планирования дня"
  }'
```

## 🛡️ Безопасность

- API-ключи **никогда не хранятся** на сервере — они передаются только по HTTPS напрямую провайдеру
- Файл `ключи.txt` (если он у вас есть) **не попадает** в репозиторий благодаря `.gitignore`
- Ключи можно подключать прямо в интерфейсе — они сохраняются только в `localStorage` вашего браузера

Этот проект демонстрирует:
- Умение писать backend на **чистом Python** (без фреймворков) и работать с HTTP API
